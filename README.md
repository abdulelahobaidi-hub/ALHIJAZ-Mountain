# نادي الجبال

تطبيق ويب لمتابعة التمارين: مؤقت فواصل، إنشاء جداول رياضية، وعدّاد أيام متتالية (Streak).
يعمل على الجوال ويمكن تثبيته على الشاشة الرئيسية.

## المزايا

- **تسجيل الدخول بحساب جوجل** — ولكل مستخدم قاعدة بيانات خاصة به في Firestore.
- **وضع محلي** يعمل بدون حساب وبدون إنترنت (البيانات على الجهاز فقط).
- **جدول عبدالاله الرياضي** — الجدول الافتراضي: ٢٠ جولة، نط الحبل بالتبادل مع تمارين القوة.
- **إنشاء جداول** — اختيار مدة التمرين المستهدفة، إضافة تمارين، وتحديد وقت العمل ووقت الراحة لكل تمرين، مع تكرار المجموعة وإحماء وتهدئة.
- **مؤقت** بتنبيه صوتي عند آخر ٣ ثوانٍ وعند كل انتقال، ومنع إطفاء الشاشة أثناء التمرين.
- **الاستمرارية (Streak)** — أيام متتالية، أطول سلسلة، وشريط آخر ٧ أيام.
- **السجل** — كل تمرين مع التاريخ وعدد الجولات والمدة، مع إمكانية حذف أي تمرين.
- **النادي** — رقم عضوية فريد لكل مستخدم، طلبات صداقة بالقبول والرفض، وقروبات بكود دعوة من ٦ خانات.
- **الأصدقاء** — شعلة ستريك 🔥 جنب كل اسم، ملف شخصي لكل صديق (إحصائياته وأيام أسبوعه وجداوله)، ومحادثة خاصة مع مشاركة الجداول.
- **القروب** — لوحة ترتيب حسب الأيام المتتالية، تحدي أسبوعي بهدف مشترك، محادثة فورية مع سجل نشاط تلقائي، وجداول منشورة ينسخها الأعضاء.

## الملفات

```
index.html              الواجهة
styles.css       التنسيق والألوان
app.js                  منطق التطبيق و Firebase
social.js               الأصدقاء والقروبات والمحادثة
firebase-config.js      إعدادات مشروع Firebase  ← عدّل هذا الملف
firestore.rules         قواعد الأمان
manifest.webmanifest    إعدادات التثبيت على الجوال
hero.jpg                صورة الغروب في شاشة الدخول
icon-*.png              أيقونات التطبيق
ex/*.webp               صور شرح التمارين (وضعية البداية والنهاية)
```

### صور التمارين

رسومات `ex/` مسمّاة بمفتاح التمرين في `LIB` و `WLIB`، وكل رسمة تعرض
وضعيتي البداية والنهاية (والبيربي ثلاث وضعيات). رُسمت كلها من الصفر
بصيغة SVG بألوان التطبيق ثم صُدِّرت WebP — لا مصادر خارجية ولا حقوق
لطرف ثالث. المصدر في `draw/`.

## الإعداد

### ١. Firebase

1. أنشئ مشروعاً على <https://console.firebase.google.com>.
2. Project settings ← Your apps ← أيقونة الويب `</>` ← انسخ `firebaseConfig`.
3. الصق القيم في `firebase-config.js`.
4. Authentication ← Sign-in method ← فعّل **Google**.
5. Authentication ← Settings ← Authorized domains ← أضف نطاق الموقع
   (`abdulelahobaidi-hub.github.io` وأي دومين مخصص).
6. Firestore Database ← أنشئ قاعدة بيانات ← تبويب Rules ← الصق محتوى
   `firestore.rules` ← Publish.

### ٢. النشر على GitHub Pages

Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root` ← Save.

### ٣. التثبيت على الجوال

افتح الرابط في المتصفح ← مشاركة ← «إضافة إلى الشاشة الرئيسية».

## بنية البيانات

```
users/{uid}/plans/{planId}        جداول المستخدم (خاصة)
users/{uid}/sessions/{sessionId}  سجل التمارين (خاص)
profiles/{uid}                    الملف العام: الاسم والصورة والستريك
memberIds/{memberId}              رقم العضوية → المستخدم
friendships/{uidA_uidB}           الصداقات
groups/{gid}                      القروب وأعضاؤه وتحدّيه
groups/{gid}/messages/{id}        المحادثة وسجل النشاط
groups/{gid}/plans/{id}           الجداول المنشورة للقروب
groupCodes/{CODE}                 كود الدعوة → القروب
friendRequests/{from_to}          طلبات الصداقة
dms/{uidA_uidB}/messages/{id}     المحادثات الخاصة
profiles/{uid}/plans/{planId}     نسخة معروضة من جداوله يشوفها أصدقاؤه
```

قواعد الأمان تمنع أي حساب من قراءة أو كتابة بيانات حساب آخر.
